# Automatic-Verification-Of-Intelligent-Systems-Project
Evolution-Trained Feed-Forward Neural Control for UAV Target Navigation in Multi-Agent Swarms

This repository contains the official implementation and simulation framework for the 25/26 AVIS course project "Evolution-Trained Feed-Forward Neural Control for UAV Target Navigation in Multi-Agent Swarms".

The repository includes:

Paper: The complete project paper detailing the methodology and results.
Modelica/ directory:
  Python scripts for training (Evolution Strategies) and testing the controller.
  The complete Modelica architecture used to model and simulate the multi-UAV swarm environment.
  Pre-trained Feed-Forward Neural Network (FFNN) weights ready for evaluation.
